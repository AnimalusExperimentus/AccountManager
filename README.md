# AccountManager


💰 3. Controlo de Despesas Pessoais
Ideia central: O utilizador regista o que ganha e o que gasta, e a app mostra para onde vai o dinheiro.
Funcionalidades:

Criar transações (valor, descrição, data, tipo: receita/despesa)
Categorias (alimentação, transporte, lazer, saúde…)
Dashboard com saldo atual, total gasto vs recebido no mês
Gráfico de pizza por categoria e gráfico de linha mensal
Filtros por período e categoria

Base de dados: tabelas users, transactions, categories — muito simples.
O que aprendes: operações CRUD completas, queries com agregações no PostgreSQL (SUM, GROUP BY), autenticação básica, gráficos no frontend.
